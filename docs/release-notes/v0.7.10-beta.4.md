### Beta highlights

**This is a public beta (prerelease), not a stable release.** It collects everything built since v0.7.9: the Android TV redesign, ExoPlayer on Android TV, phone QR scanner and provider sync fixes, subtitle improvements, and a rebuilt update checker for every platform. Earlier v0.7.10 test builds were never public, so this is the first v0.7.10 build most people will see.

Automated tests and build checks pass on every platform, but many of these changes have not been tested on real devices yet. Please report anything that behaves differently from v0.7.9.

Two things have not changed:

- Android TV plays in ExoPlayer by default; phones still use MPV by default. Both players stay available in Settings.
- Free P2P, AI Sinhala and the cloud and debrid providers work as before.

### Updating from v0.7.9

Install over your current Orvix. **Do not uninstall first**: uninstalling deletes your library, history, settings and provider sign-ins. Every platform below updates in place and keeps your data.

- **Android phones and tablets:** v0.7.9 shows "Orvix 0.7.10-beta.4 is available" when it starts. Press *Update*, then allow Android to install. You can also download `Orvix-v0.7.10-beta.4-Android-Mobile.apk` below and open it.
- **Android TV / Google TV:** v0.7.9 shows the update banner, but its buttons **cannot be reached with the TV remote**. This release fixes that. Install this version manually: download `Orvix-v0.7.10-beta.4-Android-TV.apk` with a downloader app on the TV, or copy it over with a USB drive, then open it and choose *Update*.
- **Windows:** v0.7.9 offers the update when it starts and runs `Orvix-Setup-v0.7.10-beta.4-Windows-x64.exe` for you. You can also download that installer below and run it; it updates the existing installation.
- **macOS:** v0.7.9 downloads the update and opens the ZIP, but the new app is unpacked into a temporary folder. It is easier to download `Orvix-v0.7.10-beta.4-macOS.zip` below, unzip it and move Orvix to Applications, replacing the old copy. If macOS says Orvix cannot be opened, Control-click it and choose *Open*.
- **iPhone / iPad:** v0.7.9 cannot update itself on iOS. Download the IPA for your iOS version (see below) and install it with your sideloading tool.

v0.7.9 shows its update prompt again every time it starts until you update; it has no way to remember *Later*. From this version on, *Later* is remembered.

### New update behaviour (from this version on)

- **Stable releases notify you automatically.** When a newer stable version is published, Orvix offers it when it starts.
- **Betas never pop up.** To try a newer beta, open **Settings › App updates › Check for updates**. Betas are labelled *Beta* and show their release notes.
- **Later is remembered for 24 hours** for that version. A newer stable version is still offered, and *Check for updates* always shows the latest result.
- **Honest results.** "Orvix is up to date" appears only after a successful check. If GitHub cannot be reached, is slow or limits requests, you see that instead, with a time to try again.
- **No account needed.** Update checks use the public GitHub release list and work while signed out.
- **The right file for each device.** Phones get the APK for their processor (or the universal APK), Android TV gets the TV APK, Windows gets the installer, macOS gets the ZIP. iPhone and iPad open this release page, because iOS does not let apps install their own updates.
- **Safer Android installs.** Orvix checks the downloaded APK before opening the installer and refuses one that would not install over your current Orvix.
- **macOS:** the downloaded ZIP is shown in Finder with the remaining steps, instead of being opened in a hidden folder.

### Android TV

- **ExoPlayer is the default player**, with startup that waits for real progress instead of a fixed timeout, clear errors with *Try MPV*, *Retry* and *Details*, styled subtitles, Fit / Fill / Zoom without stretching, and better remote control. MPV stays a manual choice.
- **Redesigned source picker.** The title artwork sits behind it, source modes are one segmented control, provider filters are tabs with counts, and recommended sources have a lime edge. Every filter, mode, order setting, refresh, live check and pin works as before.
- **Redesigned player controls** with a slim timeline, quiet labelled buttons, and menus that keep the remote's focus.
- **Calmer buffering.** A short stall shows nothing or a small ring; later, a compact message says what is happening ("Waiting for peers…" only while no new data arrives). There is still no time limit on slow Free P2P sources.
- **Subtitles:** the subtitle menu and *Playback info* show each track's real format (SRT, ASS, PGS, VobSub). Downloaded subtitle files are read in the right character encoding, so quotes and dashes no longer appear as boxes.
- **New menu, launcher banner and Continue Watching cards.** Focus (a solid lime pill) and selection now look different.
- **Get TorBox from my Orvix account** in Clouds › TorBox restores the TorBox connection from your phone in one press.
- **The update banner works with the remote.** Press Up at the top of a screen to reach *Update*, *What's new* and *Later*. Long release notes scroll with Up and Down.

### Android phones and tablets

- **MPV stays the default player**; ExoPlayer can be chosen in Settings.
- **TV sign-in QR scanner:** it explains why it needs the camera, recovers from camera failures with *Retry camera*, shows clear error messages with a code, offers *Open app settings*, and *Enter TV code* always works.
- **Provider sync:** *Sync now* says what happened (for example "TorBox connected from your Orvix account") and never shows a key.

### Windows, macOS, iPhone and iPad

These platforms mainly get the new update checker described above. Playback, providers and accounts are meant to work as in v0.7.9.

### Still under validation

- Real-device testing is still needed for the ExoPlayer player, the new Android TV screens, the phone QR scanner, provider sync, and the new updater's download and install on every platform.
- The Windows installer and macOS app are not code signed or notarized, so Windows SmartScreen and macOS Gatekeeper may warn.
