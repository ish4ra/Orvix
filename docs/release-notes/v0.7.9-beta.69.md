### Android-only Free P2P startup hotfix

This release retains the **beta.64-based UI, source browser, and playback architecture** used in beta.68. There is no source-list redesign and no automatic source-selection overhaul.

- **Removed the misleading 30-second startup failure for Android local P2P torrents.** Slow peer discovery or buffering does not by itself mark a torrent as failed or display the full-screen startup error. A torrent can continue starting for several minutes, or longer, while the user remains on the player screen.
- **No automatic MPV → ExoPlayer switch solely because the local torrent is slow.** The selected stream stays active. Back still allows the user to exit and release the session.
- **Genuine underlying player errors may still be reported.** This does not guarantee every torrent is playable or resolve the separate Android keyboard popup issue.

Windows, macOS and iOS are not rebuilt in this Android-only hotfix. ExoPlayer-default and the experimental automatic Free P2P selection architecture are reserved for a future release.

**Testing:** Automated CI validation covers app behavior; actual torrent startup on a physical Android device still needs testing.
