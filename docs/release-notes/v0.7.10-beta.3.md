### Beta highlights

This is a private Android Mobile and Android TV test build. It fixes problems found while testing v0.7.10-beta.2 on real devices, and it redesigns the Android TV source picker and player. Everything in v0.7.10-beta.2 is still here.

Two things have not changed:

- Android TV still plays in ExoPlayer by default, and phones still use MPV by default.
- MPV, Free P2P, AI Sinhala and the cloud and debrid providers work as before.

**Phone: TV sign-in QR scanner**

- **The QR scanner now recovers from camera failures.** Before starting, it releases any camera session an earlier scanner left open, so *Retry camera* starts from a clean state instead of repeating the same failure.
- **Clearer camera errors.** The scanner says what went wrong:
  - the camera was still busy;
  - Android could not open it;
  - the camera service did not respond;
  - a permission prompt is still open.

  It also shows the technical error code and offers *Open app settings*. When you come back from settings, it tries again.
- **Permission problems are handled separately.** If the permission is missing you see *Grant camera access*, and if Android has blocked it you see *Open app settings*. A camera failure never asks you to grant a permission you already gave. *Enter TV code* works in every case.

**Phone to TV: provider sync**

- **Sync now tells you what happened.** After it runs, you see one of:
  - "TorBox connected from your Orvix account";
  - "… saved to your Orvix account";
  - that the account has no saved provider connections yet.

  It never shows a key.
- **New TV button:** *Get TorBox from my Orvix account*, in Clouds › TorBox. It restores the TorBox connection from your phone in one press, so you never type the API key with the remote.
- **More reliable sync.** Provider credentials are now read from the account in every format the server can return them in. A request that never answers no longer blocks later syncs.

**Android TV: subtitles in ExoPlayer**

- **Correct subtitle formats.** The subtitle menu and *Playback info* now show the real format of each subtitle track in the video (SRT, ASS, PGS, VobSub), and which ones are image subtitles.
- **Subtitle track diagnostics.** *Playback info* lists every subtitle track and counts the subtitle lines the player delivered. This helps tell three cases apart: a file with no subtitles, a subtitle track that stays empty, and subtitles that really show.
- **No more stray symbols.** Downloaded and local subtitle files are now read in the right character encoding (Windows-1252 or UTF-16 as well as UTF-8). Curly quotes, dashes and "…" no longer appear as boxes or "?". Leftover markup such as `&amp;` and invisible characters is removed.

**Android TV: redesigned source picker**

- **New layout.** The title artwork sits behind the picker. The three source modes are now one segmented control, and provider filters are tabs with result counts.
- **Clearer source cards.** Each card shows:
  - a resolution tile;
  - the release name, without the repeated stats line;
  - the facts as icons;
  - a lime edge on recommended sources.
- **Easier to see where you are.** A count shows when filters hide sources, with a *Show all sources* action when nothing is left. Focus (white) and selection (lime) now look different.
- **Nothing removed.** Every filter, mode, order setting, live check and pin works as before.

**Android TV: redesigned player controls**

- **New layout.** A compact title sits above a slim timeline. Play/Pause is the main button, between the skip buttons. Subtitles, Audio, speed, picture and Next episode are quiet labelled buttons. Settings and *Switch to MPV* show their name when focused.
- **Menus use the same focus style** and say *Back to close*.
- **Buffering is less intrusive.** A short stall shows nothing, or only a small ring. After a while a compact message says what is really happening:
  - "Waiting for peers…" only while no new data arrives;
  - otherwise, how much has arrived.

  There is still no time limit on slow Free P2P sources.
- **The remote can no longer lose focus** in the player controls on large screens.

**Private updates**

- **Settings › App updates explains more failures.** It reports a timeout, a missing update function, other server errors, and an outdated server function, instead of treating them as "up to date".
- **The private update check now waits up to 20 seconds.**

**Still under validation:** every change is covered by automated tests and real-font layout tests only. The camera fix, provider sync, subtitles and the new TV screens still need testing on real devices.
