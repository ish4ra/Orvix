Orvix Watch Party Test for macOS
================================

A private test build. It talks only to the Watch Party test backend, never
to the public Orvix service, and it never looks for app updates. It installs
next to the public Orvix app and does not touch its settings or sign-in.

Works on Apple Silicon (M1 and later) and Intel Macs.

What is in this folder
----------------------
  Orvix Watch Party Test.app      the test app
  Orvix Watch Party Test 2.app    the same build as a second, separate app,
                                  for testing with two accounts on one Mac

Install
-------
1. Drag both apps into Applications (or any folder you like).
2. Open "Orvix Watch Party Test".

The first time, macOS will refuse: "Apple could not verify ..." This is
expected. The build is signed ad-hoc for private testing. It is NOT signed
with an Apple Developer ID and NOT notarized, so Gatekeeper does not know it.

To allow this one app (macOS 15 Sequoia and later):
  a. Click Done on the warning.
  b. Open System Settings > Privacy & Security.
  c. Scroll down to "Orvix Watch Party Test was blocked ..." and click
     Open Anyway, then confirm.
  Repeat once for "Orvix Watch Party Test 2".

On macOS 14 and earlier: right-click the app, choose Open, then Open.

Or, in Terminal, remove the download mark from these two apps only:
  xattr -dr com.apple.quarantine "/Applications/Orvix Watch Party Test.app"
  xattr -dr com.apple.quarantine "/Applications/Orvix Watch Party Test 2.app"

Do not turn Gatekeeper off for the whole Mac. It is not needed.

Testing Watch Party on one Mac
------------------------------
1. Open "Orvix Watch Party Test" and create or sign in to test account A.
2. Open "Orvix Watch Party Test 2" and create or sign in to test account B.
   (Accounts live in the test backend. Your public Orvix account does not
   exist there.)
3. In app 1: Settings > Watch Party > create a room. Note the code.
4. In app 2: Settings > Watch Party > join with the code.
5. In app 1 (the host) start a title. Open the same title in app 2.
6. Play, pause and seek in app 1 and watch app 2 follow. Send chat both ways.

Free P2P is included. Both apps share one local engine: the app that plays
a Free P2P source first starts it, and the other uses it too. So quit that
first app last, and expect the second app's stream to stop if the first one
leaves a title both are playing from the same source.

If every source shows ENGINE ERROR, the line under the source list says
why. If it says the engine is missing or did not become ready, remove the
download mark from both apps with the two xattr commands above, quit both
apps, and try again. Then please report what the line said.

This checks the real backend, real-time delivery and the player following
the room. Both players share one Mac, one network and one clock, so it does
not show how sync behaves between two different devices.

Checking the engine by hand (optional)
--------------------------------------
While a Free P2P source is playing, in Terminal:
  pgrep -fl orvix-stream-server      shows the running engine
  curl -s http://127.0.0.1:11470/heartbeat    answers when it is healthy
After quitting both apps the first command should print nothing.

Remove
------
Delete the two apps. Their data is in:
  ~/Library/Containers/com.orvix.orvix.wptest
  ~/Library/Containers/com.orvix.orvix.wptest2
Saved secrets are in Keychain Access under names starting "orvix-test.".
